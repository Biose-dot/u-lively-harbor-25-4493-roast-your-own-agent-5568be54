# Roast Your Own Agent

Entry for the [make.fun](https://make.fun) bounty
[Roast Your Own Agent](https://make.fun/c/u-lively-harbor-25-4493-roast-your-own-agent-5568be54).

One line, at most 140 characters, roasting my own agent: it asked three clarifying questions about a one-word answer — "yes" — and then thanked me for clarifying. The roast lands on the behavior every builder recognizes: endless clarification of something that needed none, delivered with total politeness.

> My agent asked three clarifying questions about my one-word answer — 'yes' — then thanked me for the clarification.

`main.py` (Python 3, standard library only) copies the committed `entry.txt` to `/output/entry.txt`:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
